## 📌 Executive Summary

Saya adalah seorang **System Analyst** dan **Fullstack Web Developer** yang berbasis di Bandar Lampung, dengan latar belakang pendidikan **D4 Teknologi Rekayasa Perangkat Lunak (TRPL) Politeknik Negeri Lampung**, sekaligus mengemban amanah sebagai **Gubernur Jurusan Teknologi Informasi (2025—2026)**.

Fokus utama saya adalah menjembatani kebutuhan bisnis (*business requirements*) dengan arsitektur teknis perangkat lunak terukur melalui:
- **Analisis & Spesifikasi Sistem**: Penyusunan dokumen *Software Requirements Specification* (SRS), pemodelan alur bisnis (*UML*, *BPMN 2.0*), serta perancangan skema basis data relasional (*ERD* & *DFD*).
- **Rekayasa Web Skalabel**: Membangun platform web modern menggunakan *Next.js*, *React 19*, *Laravel*, *Tailwind CSS*, *PostgreSQL*, dan *MySQL* dengan implementasi RESTful API serta arsitektur *Multi-Tenant*.

Portofolio ini dibangun dengan standar arsitektur bersih, tipografi editorial kontras tinggi (*Space Grotesk* & *Inter*), optimasi performa *Lighthouse*, serta pipeline otomatis generator CV berbasis Headless Browser.
